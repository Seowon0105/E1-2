# 📚 Python 퀴즈 게임 프로젝트

프로그래밍 언어를 배우는 가장 확실한 방법은 동작하는 프로그램을 처음부터 끝까지 직접 만들어 보는 것입니다.

이 프로젝트에서는 터미널에서 동작하는 나만의 퀴즈 게임을 구현합니다.

## 🎯 핵심 목표

Python: 입력/출력 흐름 설계 → 클래스로 구조화 → JSON으로 데이터 영속성

Git: 기능별 커밋 → 브랜치 생성/병합 → GitHub 공개

## 📝 4단계 구현

Phase 1: 기본 입출력 (사용자 입력, 퀴즈 출력, 정답 검증)

Phase 2: 객체 지향 설계 (Quiz, Player, Game 클래스)

Phase 3: 데이터 영속성 (JSON 저장/로드)

Phase 4: Git 버전 관리 (커밋, 브랜치, 병합)

## 💡 얻는 경험

문법을 아는 것과 완성된 프로그램을 만드는 것의 차이를 직접 경험합니다.

팀 협업(브랜치 전략, PR, 코드 리뷰)으로 자연스럽게 확장됩니다.

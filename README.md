# 🏀 농구 퀴즈 게임

Python으로 만든 터미널 기반 퀴즈 게임입니다.

---

## 📌 프로젝트 개요

Python 표준 라이브러리만 사용해 동작하는 콘솔 퀴즈 게임입니다.  
퀴즈 풀기 / 추가 / 목록 확인 / 최고 점수 기록 기능을 제공하며,  
게임 데이터는 `state.json`에 영속 저장됩니다.

---

## 🌌 퀴즈 주제 및 선정 이유

**주제: 농구관련 기초지식과 상식**

고등학교 시절과 대학교 시절에 농구에 관심이 많았고, 가볍게 풀 수 있는 문제라고 생각하여 농구 관련 퀴즈를 준비했습니다.

---

## ▶️ 실행 방법

```bash
# Python 3.10 이상 필요
python quiz_game.py
```

처음 실행 시 저장 파일이 없으면 기본 퀴즈 6개가 자동으로 사용됩니다.

---

## 🗂️ 기능 목록

| 번호 | 기능 | 설명 |
|------|------|------|
| 1 | 퀴즈 풀기 | 저장된 퀴즈를 순서대로 출제, 결과 및 최고 점수 갱신 |
| 2 | 퀴즈 추가 | 문제·선택지 4개·정답 번호를 입력하여 퀴즈 등록 |
| 3 | 퀴즈 목록 | 등록된 모든 퀴즈와 정답을 출력 |
| 4 | 점수 확인 | 지금까지의 최고 정답 수 확인 |
| 5 | 종료 | 데이터를 저장하고 프로그램 종료 |

**공통 예외 처리**
- 빈 입력, 문자 입력, 범위 밖 숫자 → 안내 메시지 후 재입력
- `Ctrl+C` / `EOFError` → 저장 후 안전 종료
- `state.json` 없음 / 손상 → 기본 데이터로 자동 복구

## 🗄️ 데이터 파일 설명 (`state.json`)

**경로:** 프로젝트 루트 `./state.json`  
**인코딩:** UTF-8  
**역할:** 퀴즈 목록과 최고 정답 수를 프로그램 종료 후에도 유지

**스키마 예시:**

```json
{
  "quizzes": [
    {
      "question": "NBA 역사상 통산 득점 1위 선수는?",
      "choices": ["마이클 조던",
        "코비 브라이언트",
        "르브론 제임스",
        "카림 압둘자바"],
      "answer": 3
    }
  ],
  "best_score": 2
}
```

| 키 | 타입 | 설명 |
|----|------|------|
| `quizzes` | `list` | Quiz 객체 배열. 각 항목은 `question`, `choices`, `answer` 포함 |
| `best_score` | `int` | 역대 최고 정답 수 |

## 📝 코드 구조

### `Quiz` 클래스
개별 퀴즈 1개를 표현합니다.

| 속성/메서드 | 설명 |
|-------------|------|
| `question` | 문제 텍스트 |
| `choices` | 선택지 리스트 (4개) |
| `answer` | 정답 번호 (1~4) |
| `display()` | 문제와 선택지 출력 |
| `check(n)` | 입력 번호가 정답인지 확인 |
| `to_dict()` | JSON 직렬화용 dict 반환 |
| `from_dict()` | dict에서 Quiz 인스턴스 생성 |

### `QuizGame` 클래스
게임 전체 흐름을 관리합니다.

| 속성/메서드 | 설명 |
|-------------|------|
| `quizzes` | 퀴즈 목록 |
| `best_score` | 최고 정답 수 |
| `run()` | 메인 루프 |
| `play()` | 퀴즈 풀기 진행 |
| `add_quiz()` | 새 퀴즈 입력 및 등록 |
| `list_quizzes()` | 전체 퀴즈 출력 |
| `show_score()` | 최고 점수 출력 |
| `save()` | state.json에 저장 |
| `_load()` | state.json에서 불러오기 |
